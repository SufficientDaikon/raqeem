# رقيم · raqeem

**أسهل طريقة لاستخدام نموذج Cohere المفتوح للتعرّف على الكلام العربي.**

`raqeem` (رقيم) غلافٌ خفيف حول
[`CohereLabs/cohere-transcribe-arabic-07-2026`](https://huggingface.co/CohereLabs/cohere-transcribe-arabic-07-2026)
— أدقّ نموذج مفتوح المصدر في العالم للتعرّف على الكلام العربي (لهجات + عربي/إنجليزي مختلط)،
تحت رخصة Apache 2.0. يأخذ ملفًّا صوتيًّا ويُرجِع نصًّا عربيًّا — من سطر الأوامر، أو من
بايثون، أو من أي لغة برمجة عبر استدعاء الملف التنفيذي.

الاستدلال (inference) **مُفوَّضٌ دائمًا** إلى نقطةِ نهايةٍ تختارها أنت — إمّا واجهة Cohere
المستضافة، أو خادم vLLM تشغّله بنفسك. الأداة لا تُحمِّل أوزان النموذج إطلاقًا، لذلك تبقى
خفيفة وسريعة: ملفٌّ تنفيذيٌّ واحد بلا أيّ بيئة تشغيل.

كما تمرّر المخرجات عبر تطبيعٍ عربيّ (الألف والهمزة، التاء المربوطة، التطويل والتشكيل،
والأرقام العربية إلى ASCII) حتى تحصل أدوات المعالجة اللاحقة على صورةٍ ثابتة للنص.

> بُني احترامًا لعمل Cohere Labs: نموذجٌ عربيٌّ مفتوحٌ فعلًا برخصة Apache 2.0 يستحقّ مدخلًا
> برمجيًّا من الدرجة الأولى. كلّ الفضل في الدقّة يعود إليهم — هذا المستودع مجرّد تسهيلٍ
> لاستخدامه.

## التثبيت

**بايثون** — امتدادٌ مُصرَّف، بلا `torch` وبلا عمليّاتٍ فرعية:

</div>

```bash
pip install raqeem
```

<div dir="rtl">

**ملفّ تنفيذيّ جاهز (CLI)** — نزّل نسخة لِـ Linux أو macOS أو Windows من
[صفحة الإصدارات](https://github.com/SufficientDaikon/raqeem/releases). بلا بيئة تشغيل وبلا
اعتماديّات.

**عبر cargo:**

</div>

```bash
cargo install raqeem
```

<div dir="rtl">

**من المصدر:**

</div>

```bash
git clone https://github.com/SufficientDaikon/raqeem
cd raqeem && cargo build --release   # الملفّ التنفيذيّ في target/release/raqeem
```

## الاستخدام

**واجهة Cohere المستضافة** (بلا كرت شاشة — يكفي مفتاحٌ من
[dashboard.cohere.com](https://dashboard.cohere.com/api-keys)):

</div>

```bash
export COHERE_API_KEY=...          # أو مرّره عبر --api-key
raqeem voice_note.ogg --lang ar
```

<div dir="rtl">

**خادم vLLM خاصٌّ بك** (استضافةٌ ذاتية، متوافقٌ مع OpenAI — بلا مفتاح وبلا حدودِ استخدام):

</div>

```bash
# على جهاز الـ GPU أو الخادم الافتراضيّ:
#   vllm serve CohereLabs/cohere-transcribe-arabic-07-2026 --trust-remote-code
raqeem clip.wav \
  --provider openai \
  --endpoint http://localhost:8000/v1/audio/transcriptions \
  --lang ar
```

<div dir="rtl">

لا تملك كرت شاشة؟ [`examples/serve_local.py`](examples/serve_local.py) يُشغّل النموذج على
المعالج خلف نفس نقطة النهاية.

**مخرجات JSON** (النصّ الحرفيّ + المُطبَّع + مصدر التوليد — وهذا ما تستهلكه البرامج):

</div>

```bash
raqeem voice_note.ogg --format json
```

```json
{
  "text": "الطماطم بـ ١٢٫٥ جنيه",
  "text_normalized": "الطماطم ب 12.5 جنيه",
  "provider": "cohere",
  "model": "cohere-transcribe-arabic-07-2026",
  "language": "ar"
}
```

<div dir="rtl">

الحقل `text` هو مخرَج النموذج حرفيًّا (اعرضه على الإنسان)، و`text_normalized` مُطبَّعٌ
للمطابقة — لاحظ حذف التطويل، وتحويل `١٢٫٥` إلى `12.5` **كرقمٍ واحد** لا رقمين.

## من بايثون

`pip install raqeem` يمنحك **امتدادًا أصليًّا** مبنيًّا من نفس نواة Rust — بلا `torch`، وبلا
أوزانِ نموذج، وبلا عمليّةٍ فرعية:

</div>

```python
import raqeem

t = raqeem.transcribe("voice_note.ogg", lang="ar")   # يقرأ ‎$COHERE_API_KEY
print(t.text)              # النصّ الحرفيّ، للعرض على الإنسان
print(t.text_normalized)   # مُطبَّعٌ عربيًّا، للتحليل البرمجيّ
print(t.to_dict())

# خادمك الخاصّ: مفتاح Cohere لا يُرسَل أبدًا إلى نقطة نهايةٍ مستضافةٍ ذاتيًّا — عن قصد
raqeem.transcribe("clip.wav", provider="openai",
                  endpoint="http://localhost:8000/v1/audio/transcriptions")

raqeem.normalize_ar("الطماطم بـ ١٢٫٥ جنيه")   # 'الطماطم ب 12.5 جنيه'
```

<div dir="rtl">

الأخطاء تُطلِق `raqeem.TranscriptionError`، أمّا مزوّدٌ غير صالح أو مفتاحٌ/نقطة نهاية ناقصة
فتُطلِق `ValueError`. تُشحَن ملفّات التلميحات (type stubs) مع العجلة (wheel) فيعمل الإكمال
التلقائيّ في المحرّرات. وعجلةُ `abi3` واحدة لكلّ نظام/معماريّة تغطّي CPython 3.9 فما فوق.

أيّ لغةٍ أخرى تستطيع تشغيل الملفّ التنفيذيّ مباشرة — إذ يطبع
`raqeem clip.ogg --format json` نفسَ الـ JSON على المخرَج القياسيّ.

### خياراتٌ تستحقّ المعرفة

| الخيار | الافتراضيّ | ملاحظات |
|---|---|---|
| `--model` | `cohere-transcribe-arabic-07-2026` | Cohere تتطلّب معرّفًا **مؤرّخًا** — الأسماء غير المؤرّخة تُرجِع 404. |
| `--timeout` | `300` | بالثواني، يشمل الرفع والاستدلال والتنزيل. ارفعه للاستدلال البطيء على المعالج. |
| `--api-key` | — | يرجع إلى `$RAQEEM_API_KEY`. ومع `--provider cohere` **فقط** يرجع أيضًا إلى `$COHERE_API_KEY` — وهذا المفتاح الخاصّ بِـ Cohere لا يُرسَل أبدًا إلى نقطة نهايةٍ عبر `--endpoint`. |

## الحالة — ما جرى التحقّق منه، بصدق

- **حزمة الاختبارات دون اتّصال ناجحة** (`cargo test`): وحداتُ التطبيع العربيّ، مع اختباراتِ
  نقطةِ نهايةٍ مُحاكاة تتحقّق من شكل الـ multipart وترتيب حقوله والمصادقة ومعالجة الأخطاء.
- **تفريغٌ عربيٌّ حيٌّ جرى التحقّق منه** (٢٠٢٦-٠٧-٢٢) مقابل واجهة Cohere المستضافة، وعبر
  **كلا** المُخرَجين المنشورين — عجلة PyPI والملفّ التنفيذيّ المُصدَر. كلامٌ عربيٌّ حقيقيّ
  دخل، ونصٌّ عربيٌّ صحيح خرج: سرْدٌ بحجم ٦١١ كيلوبايت عاد فقرةً دقيقةً في نحو ثانيتين، مع
  تحويل الأرقام العربية (`٢٠٠٣`) إلى ASCII في `text_normalized` كما هو مقصود. وقد تعلّقت
  محاولةٌ سابقة أثناء التطوير؛ لم تتكرّر، ولم يُثبَت سببها قطّ.
- خطآن حقيقيّان كشفتهما الاستدعاءات الحيّة وجرى إصلاحهما: Cohere تشترط ورود حقلَي `model`
  و`language` **قبل** جزء الملفّ، وتُرجِع 404 للمعرّفات غير المؤرّخة.
- **لم يجرِ التحقّق من مسار الاستضافة الذاتية.** المزوّد `openai` (وvLLM وأمثاله) وملفّ
  [`examples/serve_local.py`](examples/serve_local.py) مُنفَّذان ومُغطَّيان باختباراتِ نقطةِ
  نهايةٍ مُحاكاة، لكنّهما لم يُشغَّلا قطّ مقابل خادمٍ حقيقيّ. الطلب المُرسَل بنفس الشكل الذي
  تقبله Cohere — فاعتبره سليمًا لكن غير مُبرهَن.
- أرقام الدقّة أدناه **من Cohere** نفسها، من بطاقة النموذج. لا شيء هنا يقيس أداء النموذج على
  اللهجات أو التبديل اللغويّ.

## النموذج (كلّ الفضل لِـ Cohere Labs)

مُرمِّز Conformer بملياري معامِل + مُفكِّك Transformer، برخصة Apache 2.0. أفضل نموذجٍ عربيٍّ
مفتوح المصدر على لوحة صدارة Hugging Face للتعرّف على الكلام العربي.

| النموذج | متوسّط WER ↓ |
|---|---|
| **Cohere Transcribe Arabic** | **25.87** |
| OmniASR-7B-LLM | 28.32 |
| Whisper Large v3 | 36.86 |

كذلك: RTFx ≈ 525 (أسرع بكثير من Whisper)، ومُفضَّلٌ على Whisper في 95.8% من الاختبارات
البشرية، ويغطّي الفصحى + المصريّة والخليجيّة والشاميّة والمغاربيّة + الإنجليزية + التبديل
اللغويّ.

**ما يعطيه النموذج:** نصًّا فقط. بلا طوابع زمنية، ولا فصل متحدّثين، ولا كشف لغة، ولا VAD.
تلك بنودُ خارطة طريق `raqeem`، لا مهمّة النموذج.

## الصيغ الصوتية المدعومة

flac و mp3 و mpeg و mpga و ogg و wav. تُرسَل المقاطع كما هي (بلا فكّ ترميزٍ محلّيّ).

## خارطة الطريق

كلّ بندٍ اختياريّ ولا بدّ أن يستحقّ مكانه — النواة لا تكتسب اعتماديّةً ثقيلة من أجل ميزةٍ لم
تطلبها.

- الصوت الطويل: تقطيعٌ بِـ VAD ← **ترجمات (SRT / VTT)** بطوابع زمنية حقيقية للمقاطع.
- **فصل المتحدّثين** اختياريًّا (وحدة/نقطة نهاية منفصلة، لا اعتماديّة في النواة أبدًا).
- استعادة الترقيم والتشكيل اختياريًّا.
- **ارتباطاتٌ لغويّةٌ أصليّة** إضافية (Node/Bun و WASM) من نواة Rust ذاتها، كما هي بايثون
  اليوم — تطبيقٌ واحد، بلا نسخةٍ ثانية من المنطق تتفرّع عنه.
